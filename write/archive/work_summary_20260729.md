### 2.2 括号削减（文案优化）

**目标**：将全文中括号`（）`出现次数减少80%（303 → ~60）

**执行策略**（四轮递进）：

| 轮次 | 方法 | 文件 | 效果 |
|:----:|------|------|------|
| 第1轮 | 45条精确匹配规则 (`RULES_01`) | 01章 | 79→~30 |
| 第2轮 | 16条精确匹配规则 (`RULES_03`) | 03章 | ~180→~140 |
| 第3轮 | 21条精确匹配规则 (`MORE_03`) | 03章 | ~140→~120 |
| 第4轮 | 15条正则规则 + 字符串替换 | 03章 | ~120→19 |
| 手工 | 对02章全文重写 | 02章 | 31→1 |

**保留的括号**（均为必要保留）：
- 01章（12个）：英文缩写定义 NSIDC、CPC、AO、NAO、PNA、SST、Nino3.4、LSTM、RNN、MSE、RMSE、MAE、MAPE，以及地理坐标
- 02章（1个）：文献引用 `Liu等（2021）`
- 03章（19个）：数值对 `（0.0709，面积均值0.48）`、实验编号引用 `（E10, E17, E14, E25, E20）`、回报值 `（−8.6%）`、区域标注 `（白令海）` 等承载结果数据定位功能的括号

**关键设计决策**：
- 用 `/` 替代实验编号中的括号：`E14（AO）` → `E14/AO`
- 用逗号替代括号做插入语：`（同扇区）` → `/同扇区`
- 数值注释直接以逗号衔接：`（Δ = −8.6%）` → `，Δ = −8.6%`
- 英文术语中文简称仅在首次出现时保留括号定义，后续使用中文化表述

### 2.3 架构决策

| 决策 | 说明 |
|------|------|
| 规则+正则混合策略 | 精确匹配规则处理高频模式（安全可靠），正则规则处理变量ID/数值（批量覆盖） |
| 02章全文重写 | 02章括号密度最高（每段3-5个），精确替换后仍有大量残留，决定手工重写 |
| 不触及引用格式 | `Liu等（2021）` 是GB/T 7714引用标准格式，不可改动 |
| 缩写定义保留原则 | 学术论文规范要求首次出现的英文缩写必须附中文定义，这些括号不可削减 |
