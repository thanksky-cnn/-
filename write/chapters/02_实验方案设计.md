# 2 实验方案设计

本研究采用递进式实验设计框架，按"单变量增量→变量组合→消融验证→区域预测"的逻辑链条编排四阶段共38 个独立实验。前三个阶段以全北极海冰面积为预测目标，第四阶段扩展到七个区域海域。

**统一超参数策略。**全部38个对比实验采用相同的双编码器LSTM架构和超参数配置，仅改变辅助编码器的输入变量组合和预测目标变量。该组共享超参数包括主/辅编码器隐藏层维度、辅助序列长度、丢失率、学习率、权重衰减、梯度裁剪阈值、早停耐心值等，经预实验即E7v1的AO+SST双变量配置通过Optuna贝叶斯优化确定，具体数值详见表3.5。统一超参数策略的核心目的是确保不同实验之间的性能差异可严格归因于输入变量的信息贡献——若各实验使用独立调优的参数，则无法区分"变量信息含量差异"与"参数适配度差异"对预测性能的影响。

## 2.1 单变量增量实验

单变量增量实验旨在度量每个气候指数独立加入双编码器辅助编码器后相对于纯海冰基线的预测性能变化，从而确定各指数的独立边际贡献排序。实验设置见表3.1。

**表3.1 单变量增量实验设计**

| 实验ID | 辅助编码器输入 | 变量来源 | 实验目的 |
|:------:|---------------|:--------:|---------|
| E1 | 无/纯冰基线 | — | 单变量LSTM基准性能 |
| E7v1 | AO + SST | 极地大气+局地海洋 | 已有最优多变量参照 |
| E14 | AO only | 极地大气/全域 | AO独立贡献 |
| E8 | NAO only | 极地大气/大西洋扇区 | NAO独立贡献 |
| E10 | PNA only | 极地大气/太平洋扇区 | PNA独立贡献 |
| E9 | Nino3.4 only | 热带海洋 | ENSO独立贡献 |

单变量增量阶段的核心对比为E14/AO、E8/NAO和E10/PNA三者的相对表现排序。这三种大气遥相关型分别覆盖北极全域、大西洋扇区和太平洋扇区，若PNA显著优于NAO和AO，则支持太平洋扇区的大气环流信息对全北极海冰面积预测比大西洋扇区和全域信息更具价值的假说。该假说与Liu等（2021）关于PNA可解释太平洋扇区超过 25% 海冰面积年际方差的结论一致。

## 2.2 变量组合与消融实验

### 2.2.1 变量组合实验

变量组合实验按照"同扇区冗余→跨扇区互补→全变量信息上限"的递进假设逻辑，检验气候指数之间是否存在信息互补或相互干扰。实验设计见表3.2。

**表3.2 变量组合实验设计**

| 实验ID | 辅助编码器输入 | 变量数 | 组合类型 | 核心假设 |
|:------:|---------------|:------:|---------|---------|
| E15 | AO + NAO | 2 | 同扇区/大西洋 | 冗余假设：同扇区指数信息高度重叠，增益应弱于跨扇区组合 |
| E23 | AO + PNA | 2 | 跨扇区 | 互补假设：跨扇区组合信息正交性更高，增益应优于同扇区组合 |
| E16 | AO + Nino3.4 | 2 | 极地+热带 | 信号正交假设：来源完全独立的两变量应提供非冗余信息 |
| E17 | SST + Nino3.4 | 2 | 海洋内部 | 局地+热带海洋协同假设：两种海洋热力信号可能互补 |
| E24 | AO + NAO + PNA | 3 | 大气全扇区 | 大气信息理论饱和上限 |
| E18 | AO + SST + NAO | 3 | 大气为主+海洋 | E7v1参考配置基础上加入大西洋扇区信息 |
| E19 | AO+SST+NAO+PNA+Nino3.4 | 5 | 全变量 | 全部五个气候指数的联合信息上限 |

组合实验的关键比较为E15/AO+NAO同扇区与E23/AO+PNA跨扇区的预测性能对比。若跨扇区组合AO+PNA显著优于同扇区组合AO+NAO，则证实信息互补假说——来自不同地理扇区的大气遥相关型在物理上承载着关于海冰变化的独立信息，其联合使用可产生信息增益。若两者差异不显著甚至反转，即同扇区优于跨扇区，则表明信息冗余是主导因素——大气遥相关型的半球尺度共线性，如AO与NAO的月尺度相关系数约0.7，限制了组合使用的边际收益。

E17/SST+Nino3.4与E24/AO+NAO+PNA大气全扇区的对比则直接比较"海洋热力强迫记忆"与"大气环流全扇区信息"两种信息源对12 个月预测任务的相对价值。考虑到海洋热力变量的记忆时间3–6个月远长于大气环流的约2周，前者可能更适配月度至季节尺度的预测需求。

### 2.2.2 消融验证实验

消融验证采用反向逻辑：从全五变量组合E19中逐个移除单一指数，通过比较移除前后的性能变化反向确认各变量在多变量信息环境中的边际必要性。若移除某变量导致性能显著下降，则表明该变量提供了其他变量无法替代的独特信息；若移除后性能反而改善，则表明该变量在全变量组合中引入了净噪声。实验设计见表3.3。

**表3.3 消融验证实验设计**

| 实验ID | 配置 | 移除变量 | 验证问题 |
|:------:|------|:-------:|---------|
| E20 | 全 − NAO | NAO | NAO在已有AO+PNA的全扇区覆盖下是否冗余？ |
| E21 | 全 − Nino3.4 | Nino3.4 | 热带信号在极地大气+局地海洋信息环境中是否仍有独立价值？ |
| E22 | 全 − SST | SST | 移除局地海洋热力强迫是否导致预测性能显著下降？ |
| E25 | 全 − PNA | PNA | PNA是否提供不可替代的太平洋扇区大气信息？ |

消融验证与单变量增量实验构成互补的交叉验证逻辑链条。以PNA为例：若E10/PNA单独加入的预测增益约等于零，但E25/从全变量中移除PNA导致性能显著退化，则表明PNA单独使用时信息被其他变量共线性掩盖，但在多元信息环境中可通过与AO等变量的非线性交互发挥协同效应。反之，若E10已有增益但E25无退化效应，则表明PNA的信息可由AO+NAO的组合完全等效替代。

## 2.3 空间异质性实验

### 2.3.1 设计动机

前三个阶段均以全北极总海冰面积作为唯一的预测目标，隐含假定各海域海冰对气候指数的响应模式在空间上是同质的。然而，北极不同海域的海冰变化受不同的物理过程支配——太平洋扇区的白令海和楚科奇海主要由北太平洋风场驱动，大西洋扇区的巴伦支海和喀拉海主要受大西洋向极热量输送控制，中北冰洋则更多由局地热力学过程和海冰内部惯性主导。全北极总面积的空间平均操作可能使不同海域对气候指数的异质性响应在求和过程中正负相抵，从而系统性地低估气候指数在区域预测中的真实价值。空间异质性实验设计的直接目标是检验"扇区匹配假说"——气候指数对其物理源区对应海域的预测增益应大于对跨源区海域的增益。

### 2.3.2 实验设计

选取七个关键北极海域作为独立预测目标，为每个海域设计三个实验：纯冰基线不含气候指数、匹配指数实验即气候指数与海域属于同一物理扇区、不匹配指数实验即气候指数来自不同扇区。实验矩阵见表3.4。

**表3.4 空间异质性实验矩阵**

| 实验ID | 预测目标 | 辅助编码器输入 | 匹配类型 | 核心假说 |
|:------:|---------|:------------:|:--------:|---------|
| E26/E26a/E26b | 白令海 Bering | 无 / PNA / NAO | 基线/匹配/不匹配 | PNA/太平洋扇区应对白令海增益最大 |
| E29/E29a/E29b | 楚科奇海 Chukchi | 无 / PNA / NAO | 基线/匹配/不匹配 | PNA应对楚科奇海增益最大 |
| E27/E27a/E27b | 巴伦支海 Barents | 无 / NAO / PNA | 基线/匹配/不匹配 | NAO/大西洋扇区应对巴伦支海增益最大 |
| E30/E30a/E30b | 喀拉海 Kara | 无 / NAO / PNA | 基线/匹配/不匹配 | NAO应对喀拉海增益最大 |
| E31/E31a/E31b | 拉普捷夫海 Laptev | 无 / NAO / PNA | 基线/匹配/不匹配 | NAO应对拉普捷夫海增益最大 |
| E32/E32a/E32b | 格陵兰海 Greenland | 无 / NAO / PNA | 基线/匹配/不匹配 | NAO应对格陵兰海增益最大 |
| E28/E28a/E28b | 中北冰洋 Central Arctic | 无 / AO / SST | 基线/全域/局地 | 核心区增益预期最低 |

若匹配假说成立，预期太平洋扇区的白令海和楚科奇海的PNA增益大于NAO增益，大西洋扇区的巴伦支海、喀拉海、拉普捷夫海、格陵兰海的NAO增益大于PNA增益，且中北冰洋的AO或SST增益近零，因其不受特定扇区环流直接控制。若匹配-不匹配差异在所有海域均不显著，则"空间平均信号抵消"假说被排除，标量指数的信息瓶颈——而非空间平均——构成气候指数增量技能有限的更根本原因。

### 2.3.3 独立调参验证

上述空间异质性实验全部使用E7v1/AO+SST全北极配置的Optuna最优超参数。然而，该参数组合的aux_丢失=0.6高正则化强度是针对辅助变量信息含量较低但噪声水平较高的AO+SST组合优化得出的，可能对单变量辅助配置如NAO-only或PNA-only构成过度正则化，从而系统性低估气候指数在区域预测中的潜在价值。为此，本研究在第四阶段实验完成后，对七个海域各自的最优辅助变量配置，选取统一超参数下表现最优的组合进行Optuna 20-trial独立贝叶斯优化，调优参数空间涵盖辅助编码器学习率、权重衰减、辅助序列长度即aux_seq_len、辅助隐藏层维度即aux_hidden和辅助丢失率即aux_丢失五个关键超参数。独立调参的结果在§3.3中与统一参数结果并列讨论，以评估气候指数区域预测潜力的上限。
